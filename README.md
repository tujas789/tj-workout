# TJ Workout — ตารางฝึกแบบบันทึกได้

เว็บแอปโปรแกรมฝึกส่วนตัว: **แบดมินตัน + ความแข็งแรงของกล้ามเนื้อและเอ็น**
เปิดในมือถือข้างสนาม/ในยิม → เห็นว่าวันนี้ทำอะไร → ทำทีละท่า → จับเวลา → บันทึกลง Google Sheet

- **Stack:** HTML/JS ล้วน + Google Apps Script (`/exec` เป็น API) + Google Sheet (DB)
- **เปิดใช้งาน:** https://tujas789.github.io/tj-workout/ · repo [tj-workout](https://github.com/tujas789/tj-workout)
- **ธีม:** Instrument Panel (นีโอบรูทัลลิสต์) จาก `theme-kit` ของ TJ Inventory — accent น้ำเงิน

## แก้โค้ดแล้วเอาขึ้นเว็บยังไง
ไฟล์ทำงานอยู่ใน OneDrive (ซิงก์ Mac ↔ Windows) · git repo อยู่**นอก** OneDrive (ซิงก์ผ่าน GitHub)
เพราะ `.git` ใน OneDrive พังแน่เมื่อใช้ 2 เครื่อง — ดู [DEPLOY.md](docs/DEPLOY.md)

```bash
./sync-to-repo.sh "fix: สรุปสั้นๆ"     # 🍎 copy + commit + push
```
```powershell
.\sync-to-repo.ps1 "fix: สรุปสั้นๆ"    # 🪟
```

## โปรแกรมฝึกมาจากไหน
ผ่านการซักถามกัน 6 รอบ (`/grill-with-docs`) จนแก้ฉบับแรกไป 13 จุด สิ่งที่กำหนดรูปร่างมากที่สุด:

- **ช่องว่างกล้ามเนื้อ–เอ็น** — เคยเล่นเวทแล้วหยุด 4 ปี ตอนอายุ 38: กล้ามเนื้อคืนแรงเร็ว เอ็นไม่มี
  กลไกความจำแบบนั้น → [ADR-0001](docs/adr/0001-slow-ramp-first-six-weeks.md) ไต่ช้าโดยตั้งใจ 6 สัปดาห์แรก
- **นาฬิกาไม่ได้ใช้จับ "ยกจนหมดแรง"** — ย้ายไปจับท่าค้าง คุมจังหวะ บล็อกความหนาแน่น และจับเวลาพัก
- **เกมคู่ ไม่ใช่เกมเดี่ยว** — ข้อศอกกับไหล่มาก่อนเข่าในลำดับความเสี่ยง
- **มังสวิรัติแบบกินไข่ ไม่กินนมวัว ไม่ใช้อาหารเสริม** — เป้าโปรตีน ~120–130 g/วัน
- **บางสัปดาห์ทำไม่ครบ** → มีโดสขั้นต่ำ 12 นาที (งานเอ็นล้วน) และลำดับ `ยิม > บ้าน B > บ้าน A`
- **ไม่ฟิกวันในปฏิทิน** → เซสชันหมุนเป็น**รอบ** แอปดูจากประวัติว่าทำอะไรไปล่าสุดเมื่อไหร่
  แล้วเสนออันถัดไป พร้อมกติการะยะห่าง (ยิมห่างวันทดสอบ ≥2 วัน) — เสนอแต่ไม่บังคับ
