TJ Workout

ตารางฝึกแบบบันทึกได้ — เปิดจากมือถือ เห็นว่าวันนี้ทำอะไร ทำทีละท่า จับเวลาให้ แล้วเก็บลง Google Sheet เอง
เปิดที่: tujas789.github.io/tj-workout

ครั้งแรกทำอะไรบ้าง

  1. เปิดลิงก์ในมือถือ แล้วกด แชร์ → เพิ่มไปยังหน้าจอโฮม จะได้ไอคอนเปิดง่าย ๆ เหมือนแอป
  2. ดูป้ายมุมขวาบน ถ้าขึ้น ซิงก์แล้ว สีเขียว = ต่อกับชีตได้แล้ว ไม่ต้องตั้งอะไรเพิ่ม
  3. เริ่มที่หน้า "เช้านี้" ให้คะแนนปวดของเช้าวันนี้ — เป็นตัวเลขที่สำคัญที่สุดในระบบ และใช้เวลา 10 วินาที

วันหนึ่งใช้ยังไง

มีอยู่ 3 จังหวะเท่านั้น ไม่ต้องเปิดแอปทั้งวัน

ตอนตื่นนอน — แท็บ เช้านี้

ให้คะแนนปวด 0–10 เลือกจุดที่ปวด ใส่ชั่วโมงนอน แล้วกดบันทึก

ทำไมต้องทุกเช้า: คะแนนปวดตอนเช้าคือตัวชี้วัดเอ็นที่ดีที่สุดที่วัดเองได้ ความรู้สึกตอนกำลังยกโกหกได้ แต่เช้าวันรุ่งขึ้นไม่โกหก ถ้าค่าเฉลี่ยรายเดือนเริ่มไต่ขึ้น แปลว่ากล้ามเนื้อกำลังแซงเอ็น ให้ลดน้ำหนักลง 20%

พอบันทึกแล้ว เกจวัดความพร้อมจะติ๊กให้เอง 2 ข้อจาก 3

ตอนจะฝึก — แท็บ วันนี้

แอปบอกเองว่าถัดไปควรทำอะไร กด เริ่มเซสชัน แล้วทำตามทีละท่า

  • กด ปุ่มใหญ่สีน้ำเงิน เพื่อเริ่มจับเวลา หรือบันทึกเซ็ต (แล้วแต่ชนิดท่า)
  • ท่าที่ต้องใส่ตัวเลข จะมีช่อง น้ำหนัก กับ ครั้ง โผล่มาให้
  • ทำท่าไหนไม่ได้ กด ข้าม → ได้เลย ไม่ต้องรู้สึกผิด
  • ออกกลางคัน กด ออก — ที่บันทึกไปแล้วยังอยู่

หลังลงสนามแบด — แท็บ วันนี้ เลื่อนลงล่าง

การ์ด "หลังลงสนามแบด" ให้กรอก 2 อย่าง ใช้เวลา 30 วินาที

  • แรงตก 0–10 — เกมสุดท้ายเทียบเกมแรก (0 = เหมือนเดิม, 10 = แทบไม่เหลือ)
  • ตีเหนือหัวเต็มแรงได้ถึงเกมที่เท่าไหร่ ก่อนเริ่มต้องออมแรง

ตัวที่สองคือของจริงสำหรับเป้าหมาย "ไม่มีใครสู้ long rally ได้" — ในเกมคู่มันแปลว่า คุณยังตบเต็มแรงได้ตอนที่คนอื่นเริ่มตบเบาลงแล้ว ตัวเลขนี้จะขยับช้า คาดหวังการเปลี่ยนแปลงที่วัดได้ราว 8–12 สัปดาห์

กดบันทึกแล้ว วันยิมจะถูกเลื่อนออกไปให้อัตโนมัติ เพราะขาหนักต้องห่างวันลงสนาม 2 วัน

สามแท็บ

แท็บไว้ทำอะไรใช้บ่อยแค่ไหน
วันนี้เซสชันถัดไป · เกจวัดความพร้อม · บันทึกหลังลงสนามทุกวันที่ฝึก
รอบนี้ดูภาพรวมว่าทำอะไรไปแล้ว · เลือกทำเซสชันไหนก็ได้ · ตารางบล็อก 5 สัปดาห์สัปดาห์ละครั้ง
เช้านี้คะแนนปวด · ชั่วโมงนอน · ทดสอบรายเดือนทุกเช้า

ทำไมไม่มี "วันจันทร์ทำอะไร"

เพราะชีวิตจริงไม่ได้เดินตามปฏิทิน บางสัปดาห์ทำได้ 3 ครั้ง บางสัปดาห์ได้ครั้งเดียว ระบบนี้จึงคิดเป็น "รอบ" ไม่ใช่ตารางประจำสัปดาห์

บ้าน B → ยิม → บ้าน A → บ้าน B → …

ทำอันหนึ่งเสร็จ อันถัดไปคืออันต่อจากนั้น จะทำวันไหนก็ได้ แอปจำจากประวัติว่าคุณทำอะไรไปล่าสุดเมื่อไหร่ แล้วเสนออันถัดไปให้

กติการะยะห่าง 2 ข้อ

  • เซสชันเดิมห่างกันอย่างน้อย 2 วัน
  • วันยิมต้องห่างวันลงสนามอย่างน้อย 2 วัน — ขาหนักกับแบดแย่งการฟื้นตัวกัน

ถ้าติดกติกา แอปจะข้ามไปเสนออันถัดไป และบอกเหตุผลว่าข้ามอะไรเพราะอะไร ถ้าติดหมดก็จะเสนอปั่นเบาแทน — แต่ในหน้า "รอบนี้" กดทำอันไหนก็ได้เสมอ แค่ถามยืนยันก่อน

สัญลักษณ์ในหน้า "รอบนี้"

สัญลักษณ์แปลว่า
▶อันที่แอปเสนอให้ทำถัดไป
⏸ติดกติการะยะห่าง (มีบอกเหตุผลใต้ชื่อ)
○ทำได้ แต่ยังไม่ถึงคิวตามลำดับ

นาฬิกา 4 แบบ

นี่คือเหตุผลที่งานนี้เป็นแอปไม่ใช่กระดาษ — แต่ละชนิดท่า นาฬิกาทำงานคนละอย่าง

ป้ายบนการ์ดนาฬิกาทำอะไรตัวอย่างท่า
ท่าค้างนับถอยหลังตามวินาที จบแล้วนับเวลาพักต่อ แล้วขึ้นเซ็ตถัดไปเองWall sit 45 วิ
ยกโชว์จังหวะ (เช่น 3-1-1) ให้ใส่น้ำหนัก/ครั้ง กดบันทึกแล้วจับเวลาพักให้Leg press
อินเทอร์วัลสลับเร่ง/ผ่อนให้เอง นับรอบให้ ไม่ต้องจำปั่นจักรยาน
จับเวลานับถอยหลังอย่างเดียววอร์ม · คูลดาวน์

หมดเวลาแล้วจะมีเสียงและสั่น และมีเสียงเตือนล่วงหน้า 3 วินาที — ไม่ต้องจ้องจอ
จังหวะ 3-1-1 อ่านว่า: ลง 3 วินาที · ค้างล่าง 1 วินาที · ขึ้น 1 วินาที

เรื่องนาฬิกาที่ต้องเข้าใจให้ตรงกัน

นาฬิกาตัวนี้ ไม่ได้มีไว้จับว่ายกได้นานแค่ไหนจนหมดแรง เพราะกล้ามเนื้อตอบสนองต่อความล้า แต่เอ็นตอบสนองต่อขนาดของแรง ยกของเบาจนหมดแรง = กล้ามเนื้อล้าแต่เอ็นแทบไม่ได้อะไร

มันจึงถูกวางไว้ 4 ที่ที่ให้ผลจริง: จับท่าค้าง · คุมจังหวะ · คุมความหนาแน่น · จับเวลาพัก
และให้หยุดเซ็ตตอนที่ยังเหลือแรงอีก 1–3 ครั้ง ไม่ใช่ยกจนหมดแรง

แถบส้ม "ช่วงไต่ช้า"

6 สัปดาห์แรก นับจากเซสชันหลักครั้งแรกที่บันทึก จะมีแถบสีส้มบอกว่าเหลืออีกกี่วัน พร้อมข้อความว่า "ยกเบากว่าที่ทำได้ ~30% ไม่ว่าตารางข้างล่างจะบอกว่าอะไร"

มันจะน่าหงุดหงิด และนั่นคือสัญญาณว่ามันทำงาน — ความรู้สึกว่า "เบาไป เสียเวลา" มาจากกล้ามเนื้อที่พร้อมแล้ว ในขณะที่เอ็นยังไม่พร้อม กล้ามเนื้อที่เคยฝึกมาคืนแรงใน 6–10 สัปดาห์ แต่เอ็นไม่มีกลไกความจำแบบนั้น ต้องสร้างใหม่ตามอัตราของมันเอง

เหตุผลเต็ม ๆ อยู่ใน docs/adr/0001-slow-ramp-first-six-weeks.md · พ้น 6 สัปดาห์แถบจะหายไปเอง

สัปดาห์ที่ทำไม่ครบ

ไม่ต้องรู้สึกผิดและไม่ต้องเริ่มใหม่ มีทางออกวางไว้ให้แล้ว 2 ทาง

1. ตัดจากท้ายก่อน

ยิม > บ้าน B > บ้าน A

เหลือได้แค่ครั้งเดียว → เอาวันยิม เพราะเป็นวันเดียวที่เพิ่มน้ำหนักได้จริง

2. โดสขั้นต่ำ 13 นาที

ปุ่ม "เวลาไม่พอ → โดสขั้นต่ำ" ในหน้าวันนี้ — มีแต่งานเอ็น ไม่มีคาร์ดิโอ ไม่มีส่วนบน

ที่มีแต่งานเอ็นเพราะ กล้ามเนื้อทนการหยุดหนึ่งสัปดาห์ได้สบาย แต่เอ็นไม่ทน เอ็นตอบสนองต่อความสม่ำเสมอมากกว่าความหนัก

ข้อมูลไปอยู่ไหน

ทุกอย่างเขียนลงเครื่องก่อนเสมอ แล้วค่อยส่งขึ้น Google Sheet เมื่อมีเน็ต

ป้ายมุมขวาบนแปลว่าต้องทำอะไรไหม
ซิงก์แล้วส่งขึ้นชีตครบแล้วไม่ต้อง
รอส่ง 5มี 5 แถวรออยู่ในเครื่องไม่ต้อง — ส่งเองเมื่อมีเน็ต
ตั้งค่า APIยังไม่ได้ต่อกับชีตแตะป้าย แล้ววาง URL

ในยิมหรือสนามที่สัญญาณไม่ดี กดบันทึกได้ตามปกติ ข้อมูลไม่หาย แค่ค้างเป็น "รอส่ง n" แล้วส่งเองตอนกลับมามีเน็ต — ปิดแอปไปเลยก็ได้

อยากดูกราฟ

เปิดชีตแล้วใช้ Insert → Chart ของ Google เอา — ฟรีและดีกว่าที่จะเขียนหน้ากราฟในแอป กราฟที่ควรทำ: คะแนนปวดรายวัน · น้ำหนัก Leg press/RDL รายสัปดาห์ · ผลทดสอบรายเดือน

โครงชีตทั้ง 5 ใบอธิบายไว้ใน docs/SCHEMA.md

การ์ดตั้งค่า (แตะป้ายมุมขวาบน)

  • URL ของ Apps Script — ปกติไม่ต้องแตะ ใช้ตอน redeploy แล้ว URL เปลี่ยน
  • ล้างประวัติในเครื่อง — รีเซ็ตตัวนับ "เซสชันหลัก n/3" แล้วเริ่มรอบใหม่

ระวัง: มีสองที่ให้ล้าง คนละชุดกัน

  • ในแอป → ล้างประวัติในมือถือ (ตัวที่ใช้คำนวณว่ารอบถัดไปทำอะไร)
  • ใน Apps Script → ล้างข้อมูลในชีต (ฟังก์ชัน clearLogs())

ล้างที่เดียวไม่พอ ถ้าล้างแค่ชีต แอปจะยังนับรอบต่อจากของเดิม · รายละเอียดใน docs/SCHEMA.md

แก้ปัญหา

อาการสาเหตุ · วิธีแก้
ป้ายค้างที่ รอส่ง n นานไม่มีเน็ต หรือชีตมีปัญหา — ลองเปิดแอปใหม่ตอนมีเน็ต ข้อมูลไม่หายแน่นอน
ป้ายขึ้น ตั้งค่า API ทั้งที่เคยใช้ได้เคยกรอก URL ทับไว้แล้วผิด — แตะป้าย แล้วลบช่อง URL ให้ว่าง กดบันทึก จะกลับไปใช้ค่าในโค้ด
กดบันทึกแล้วขึ้น เซิร์ฟเวอร์ขัดข้อง (HTTP 403)สคริปต์ยังไม่ได้รับสิทธิ์ — เปิด Apps Script แล้ว Run setup หนึ่งครั้ง (ดู docs/DEPLOY.md)
แอปเสนอเซสชันที่เพิ่งทำไปประวัติในเครื่องถูกล้าง — บันทึกเซสชันถัดไปตามปกติ เดี๋ยวลำดับก็เข้าที่
ตัวเลขในชีตกลายเป็นวันที่คอลัมน์ใหม่ยังไม่ถูกตั้งเป็นข้อความ — เพิ่มลง TEXT_COLS ใน 00_setup.gs แล้ว Run setup ใหม่
เปิดเว็บแล้วเป็นของเก่ามือถือ cache ไว้ — ปิดแท็บแล้วเปิดใหม่ หรือดึงหน้าลงเพื่อรีเฟรช

เกณฑ์ 3 ตัวที่ใช้ตัดสินทุกครั้ง

  • ปวดระหว่างทำ ≤ 3/10 → ปลอดภัย ทำต่อได้
  • ปวดที่เพิ่มขึ้นต้องหายภายใน 24 ชั่วโมง
  • เช้าวันรุ่งขึ้นคือตัวชี้วัดจริง ไม่ใช่ความรู้สึกตอนกำลังทำ

เกินเกณฑ์ → ลดน้ำหนักลง 20% แต่อย่าหยุดทำ เอ็นที่ถูกพักสนิทจะอ่อนแอลง ไม่ใช่ดีขึ้น
