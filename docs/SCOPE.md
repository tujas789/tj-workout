# SCOPE.md — ขอบเขต MVP

## ปัญหาที่แก้
โปรแกรมฝึกที่เป็นเอกสาร **จับเวลาให้ไม่ได้** และ **บันทึกไม่ได้** — สองอย่างนี้คือทั้งหมด
ที่ทำให้โปรเจกต์นี้ควรมีอยู่ ไม่งั้นใช้เอกสารก็พอ

## MVP (ตกลงแล้ว)
- [x] หน้า **วันนี้** — เซสชันของวันนี้ + เกจวัดความพร้อม 3 ข้อ
- [x] **ตัวรันเซสชัน** — ทีละท่า พร้อมคำเตือนฟอร์มและตัวสำรองถ้ายิมไม่มีเครื่อง
- [x] **นาฬิกา 4 แบบ** — ท่าค้าง · พัก · อินเทอร์วัล · จับเวลา (พร้อมเสียง + สั่น)
- [x] **บันทึกน้ำหนัก/ครั้ง** รายเซ็ต
- [x] หน้า **เช้านี้** — คะแนนปวด 0–10 + จุดที่ปวด + ชั่วโมงนอน + ทดสอบรายเดือน
- [x] หน้า **สัปดาห์** — ตารางทั้งสัปดาห์ + บล็อก 5 สัปดาห์ (กดเข้าเซสชันไหนก็ได้)
- [x] **โดสขั้นต่ำ 12 นาที** สำหรับสัปดาห์ที่ทำไม่ครบ
- [x] **คิวออฟไลน์** — เขียน localStorage ก่อนเสมอ แล้ว sync ขึ้นชีตเมื่อมีเน็ต

## ไม่ทำใน MVP (V2)
- ❌ **หน้ากราฟ/ประวัติในแอป** — ใช้ Insert → Chart ของ Google Sheet แทน ฟรีและดีกว่า
- ❌ ดึงโปรแกรมจากชีต (`getProgram`) — API พร้อมแล้วแต่ frontend ยังอ่านจาก `program.js`
- ❌ PWA ติดตั้งลงโฮมสกรีน (ขาดไอคอน)
- ❌ auth — ผู้ใช้คนเดียว
- ❌ บันทึกวันแบด (แรงตก / ตีเหนือหัวถึงเกมไหน) — ยังใช้ช่องทดสอบไปก่อน
