# SCOPE.md — ขอบเขต MVP

## ปัญหาที่แก้
โปรแกรมฝึกที่เป็นเอกสาร **จับเวลาให้ไม่ได้** และ **บันทึกไม่ได้** — สองอย่างนี้คือทั้งหมด
ที่ทำให้โปรเจกต์นี้ควรมีอยู่ ไม่งั้นใช้เอกสารก็พอ

## MVP (ตกลงแล้ว)
- [x] หน้า **วันนี้** — เซสชันของวันนี้ + เกจวัดความพร้อม 3 ข้อ
- [x] **ตัวรันเซสชัน** — ทีละท่า พร้อมคำเตือนฟอร์มและตัวสำรองถ้ายิมไม่มีเครื่อง
- [x] **นาฬิกา 4 แบบ** — ท่าค้าง · พัก · อินเทอร์วัล · จับเวลา (พร้อมเสียง + สั่น)
- [x] **บันทึกน้ำหนัก/ครั้ง** รายเซ็ต
- [x] หน้า **เช้านี้** — คะแนนปวด 0–10 + จุดที่ปวด + ชั่วโมงนอน + ทดสอบรายเดือน
- [x] หน้า **สัปดาห์** — ตารางทั้งสัปดาห์ + บล็อก 5 สัปดาห์ (กดเข้าเซสชันไหนก็ได้)
- [x] **โดสขั้นต่ำ 12 นาที** สำหรับสัปดาห์ที่ทำไม่ครบ
- [x] **คิวออฟไลน์** — เขียน localStorage ก่อนเสมอ แล้ว sync ขึ้นชีตเมื่อมีเน็ต
- [x] **บันทึกวันทดสอบ** — แรงตก 0–10 + ตีเหนือหัวถึงเกมไหน (เลื่อนขึ้นจาก V2 ตามที่เจ้าของขอ
      หลังพบว่าข้อความ "ลงเต็มที่ บันทึกผลได้" สัญญาไว้แต่ไม่มีปุ่มให้กด)
- [x] **การ์ดตั้งค่า** — เปลี่ยน URL `/exec` · ล้างประวัติในเครื่อง (เจ้าของขอเพิ่มระหว่างทาง)
- [x] **PWA manifest** — เลื่อนขึ้นจาก V2 เพราะสร้างไปแล้วและ Add to Home Screen ใช้ได้จริง
      ⚠️ ยังไม่มีไอคอนของตัวเอง

- [x] **ดึงโปรแกรมจากชีต** (`getProgram`) — ชีต Program คือของจริง แก้ท่า/โดสไม่ต้อง deploy
      `program.js` เหลือหน้าที่เดียว: ตัวสำรองตอนออฟไลน์/ยังไม่ได้เติมชีต
- [x] **วัดความก้าวหน้า** — เจ้าของขอเพิ่มหลังส่งมอบ MVP · ทำสองที่ คนละหน้าที่:
      ชีต `สรุป` = กราฟจริง (`buildDashboard()`) · แท็บ "ก้าวหน้า" ในแอป = ตัวเลขล้วน
      เทียบ 28 วันล่าสุดกับ 28 วันก่อนหน้า ไว้ดูเร็ว ๆ ข้างสนาม

## ไม่ทำใน MVP (V2)
- ❌ **หน้ากราฟ (เส้น) ในแอป** — ยังยืนตามเดิม ใช้ Insert → Chart ของ Google Sheet
      แท็บ "ก้าวหน้า" ที่เพิ่มมาเป็น**ตัวเลข** ไม่ใช่กราฟ — ทำสิ่งที่ชีตทำไม่ได้คือตอบเร็วข้างสนาม
- ❌ ไอคอน PWA ของตัวเอง
- ❌ auth — ผู้ใช้คนเดียว
- ❌ read API อื่นนอกจาก `ping`/`getProgram`/`progress` — `?action=recent` เคยมีแล้วถอดออก
      เพราะเป็น endpoint สาธารณะที่ไม่มี auth และ frontend ไม่ได้เรียก
      ⚠️ `progress` ส่งกลับแค่ **ตัวเลขสรุป** ไม่ใช่แถวดิบ — ตั้งใจให้เปิดเผยน้อยที่สุด
