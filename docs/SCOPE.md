# SCOPE.md — ขอบเขต MVP

## ปัญหาที่แก้
โปรแกรมฝึกที่เป็นเอกสาร **จับเวลาให้ไม่ได้** และ **บันทึกไม่ได้** — สองอย่างนี้คือทั้งหมด
ที่ทำให้โปรเจกต์นี้ควรมีอยู่ ไม่งั้นใช้เอกสารก็พอ

## MVP (ตกลงแล้ว)
- [x] หน้า **วันนี้** — เซสชันของวันนี้ + เกจวัดความพร้อม 3 ข้อ
- [x] **ตัวรันเซสชัน** — ทีละท่า พร้อมคำเตือนฟอร์มและตัวสำรองถ้ายิมไม่มีเครื่อง
- [x] **นาฬิกา 4 แบบ** — ท่าค้าง · พัก · อินเทอร์วัล · จับเวลา (พร้อมเสียง + สั่น)
- [x] **บันทึกน้ำหนัก/ครั้ง** รายเซ็ต
- [x] หน้า **เช้านี้** — คะแนนปวด 0–10 + จุดที่ปวด + ชั่วโมงนอน + ทดสอบรายเดือน
- [x] หน้า **สัปดาห์** — ตารางทั้งสัปดาห์ + บล็อก 5 สัปดาห์ (กดเข้าเซสชันไหนก็ได้)
- [x] **โดสขั้นต่ำ 12 นาที** สำหรับสัปดาห์ที่ทำไม่ครบ
- [x] **คิวออฟไลน์** — เขียน localStorage ก่อนเสมอ แล้ว sync ขึ้นชีตเมื่อมีเน็ต
- [x] **บันทึกวันทดสอบ** — แรงตก 0–10 + ตีเหนือหัวถึงเกมไหน (เลื่อนขึ้นจาก V2 ตามที่เจ้าของขอ
      หลังพบว่าข้อความ "ลงเต็มที่ บันทึกผลได้" สัญญาไว้แต่ไม่มีปุ่มให้กด)
- [x] **การ์ดตั้งค่า** — เปลี่ยน URL `/exec` · ล้างประวัติในเครื่อง (เจ้าของขอเพิ่มระหว่างทาง)
- [x] **PWA manifest** — เลื่อนขึ้นจาก V2 เพราะสร้างไปแล้วและ Add to Home Screen ใช้ได้จริง
      ⚠️ ยังไม่มีไอคอนของตัวเอง

- [x] **ดึงโปรแกรมจากชีต** (`getProgram`) — ชีต Program คือของจริง แก้ท่า/โดสไม่ต้อง deploy
      `program.js` เหลือหน้าที่เดียว: ตัวสำรองตอนออฟไลน์/ยังไม่ได้เติมชีต
- [x] **วัดความก้าวหน้า** — เจ้าของขอเพิ่มหลังส่งมอบ MVP · **ทำที่ชีตอย่างเดียว**
      ชีต `สรุป` + กราฟ 4 อัน (`buildDashboard()`) · ต้อง login Google ถึงจะดูได้

## ไม่ทำใน MVP (V2)
- ❌ **หน้าดูความก้าวหน้าในแอป ไม่ว่ารูปแบบไหน** — ทั้งกราฟและตัวเลข
      เคยทำแท็บ "ก้าวหน้า" (ตัวเลข) ไปแล้วรอบหนึ่ง แล้ว**ถอดออกทั้งหมด** ดูเหตุผลด้านล่าง
- ❌ ไอคอน PWA ของตัวเอง
- ❌ auth — ผู้ใช้คนเดียว
- ❌ **read API อื่นนอกจาก `ping`/`getProgram`** — `?action=recent` และ `?action=progress`
      เคยมีทั้งคู่แล้วถอดออกทั้งคู่ ด้วยเหตุผลเดียวกัน (ดูด้านล่าง)

## บทเรียน: ทำไมไม่มีหน้าดูความก้าวหน้าในแอป
รอบที่แล้วเคยเพิ่ม `?action=progress` + แท็บ "ก้าวหน้า" เข้ามา แล้วรีวิวจับได้ 2 เรื่อง:

1. **`/exec` เป็น endpoint สาธารณะไม่มี auth** (ตั้งใจ — ผู้ใช้คนเดียว) การเพิ่ม read API
   ที่ตอบ *สรุปสุขภาพ* จึงเท่ากับเปิดคะแนนปวด ชั่วโมงนอน ผลทดสอบ ให้ใครก็ตามที่รู้ URL
   ข้อแก้ตัวว่า "ส่งแค่ตัวเลขสรุป ไม่ใช่แถวดิบ" ไม่ตรงประเด็น — สรุปสุขภาพก็คือข้อมูลสุขภาพ
2. **การ์ด "น้ำหนักสูงสุดต่อท่า" ขัดหลักการข้อ 4** — ค่าสูงสุด + ลูกศรเขียวคือ PR display
   ซึ่ง `CONTEXT.md` เขียนห้ามไว้เอง (*เลี่ยงการนำเสนอเป็น: สถิติส่วนตัว, PR, สตรีค*)

ชีต `สรุป` ไม่มีปัญหาทั้งสองข้อ: อยู่หลัง login Google และเป็นกราฟเทรนด์ ไม่ใช่ป้ายคะแนน
**อยากดูความก้าวหน้า = เปิดชีต** ยอมแลกความสะดวกข้างสนามกับความเป็นส่วนตัว
