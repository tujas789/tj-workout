## ⚠️ คอลัมน์ที่ต้องเป็นข้อความล้วน
Google Sheets แปลงค่าที่ "หน้าตาเหมือนวันที่" ให้เองเงียบ ๆ — เจอจริงตอนทดสอบ:
`3-1-1` (จังหวะ) กลายเป็น 3 ม.ค. 2001 · `6/7` (ทำครบกี่ท่า) กลายเป็น 6 ก.ค. · `6-8` (ช่วงครั้ง) กลายเป็นวันที่

`setup()` จึงบังคับ `setNumberFormat('@')` ให้คอลัมน์เหล่านี้ (ดู `TEXT_COLS` ใน `00_setup.gs`):
`Program.reps` `Program.tempo` · `Session.done` · `SetLog.reps` `SetLog.note`

คอลัมน์ `date` กับ `time` **ปล่อยให้แปลงตามปกติ** — เป็นวันที่/เวลาจริงแล้วทำกราฟง่ายกว่า

## Program — นิยามโปรแกรม
| คอลัมน์ | ความหมาย |
|---|---|
| `session_key` | `gym` · `homeA` · `homeB` · `easy` · `min` |
| `order` | ลำดับท่าในเซสชัน |
| `ex_id` `name` | รหัสท่า + ชื่อที่แสดง |
| `type` | `hold` ท่าค้าง · `reps` ยก · `interval` · `time` จับเวลา — กำหนดว่านาฬิกาทำงานยังไง |
| `sets` `reps` `tempo` `hold` `rest` | โดส (`hold`/`rest` เป็นวินาที) |
| `cue` `alt` `why` | คำเตือนฟอร์ม · ตัวสำรองถ้ายิมไม่มีเครื่อง · เหตุผลที่มีท่านี้ |
| `secs` | วินาที — ใช้เฉพาะ `type = time` (วอร์ม/คูล/ปั่นเบา) |
| `log` | `Y` = ท่านี้มีช่องบันทึกน้ำหนัก/ครั้ง · ว่าง = ทำเฉย ๆ ไม่ต้องบันทึก |

**★ แก้โปรแกรม = แก้แถวในใบนี้ ไม่ต้อง deploy ใหม่** — เหตุผลที่ออกแบบแบบนี้คือโปรแกรมถูกปรับ
13 จุดตั้งแต่ฉบับแรก และจะปรับอีกเรื่อย ๆ

### แอปอ่านใบนี้ยังไง
เปิดแอป → วาดด้วยของที่มีในเครื่องทันที (แคช → ถ้าไม่มีก็ `frontend/program.js`)
→ แล้วค่อยยิง `?action=getProgram` เบื้องหลัง ได้มาแล้วค่อยวาดทับ + เก็บแคช
**ไม่มีเน็ตก็ฝึกได้เสมอ** (หลักการข้อ 1) · ดูที่มาของท่าได้ที่การ์ดตั้งค่า บรรทัด "ท่ามาจาก…"

ใบนี้เก็บ **เฉพาะรายการท่า** — `cycle` · กติการะยะห่าง · interval · บล็อก 5 สัปดาห์ ·
ท่าทดสอบ · เกจความพร้อม ยังอยู่ใน `program.js` เพราะเป็น**ตรรกะ** ไม่ใช่โดส
### ชีตทับได้แค่ไหน — อ่านให้ชัดก่อนแก้ชีต
- ทับ **รายเซสชัน** ไม่ใช่ทั้งก้อน — เซสชันที่ชีตไม่มีแถว จะยังใช้ของสำรองในแอป
  ⚠️ **ลบท่าออกจากชีตจนหมดเซสชัน ไม่ได้ทำให้เซสชันนั้นหายไป** มันจะกลับไปใช้ของในโค้ดแทน
  การ์ดตั้งค่าจะขึ้นเตือนว่าเซสชันไหนใช้ของสำรองอยู่ จะได้ไม่เข้าใจผิด
- แถวที่ `session_key` ไม่ตรงกับเซสชันที่โค้ดรู้จัก → ข้าม (เพิ่มเซสชันใหม่จากชีตอย่างเดียวไม่ได้)
- **แถวที่ตั้งนาฬิกาไม่ได้ → ข้าม** และรายงานจำนวนที่การ์ดตั้งค่า:
  `type=time` ต้องมี `secs` · `type=hold` ต้องมี `hold` + `sets` · `type=reps` ต้องมี `sets`
  ปล่อยผ่านไม่ได้เพราะจะกลายเป็นนาฬิกา NaN กลางเซสชัน ซึ่งแย่กว่าไม่ดึงจากชีตเลย

### เติมใบนี้ครั้งแรก
```bash
node tools/gen-program-rows.js     # อ่าน program.js → เขียน gas/working/03_program_seed.gs
```
แล้ว `clasp push` → เปิด editor → Run `setup()` → Run `seedProgram()`

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `seedProgram()` | เติมใบที่ยัง**ว่าง** — ถ้ามีแถวอยู่แล้วจะ **throw ไม่ยอมเขียนทับ** |
| `resetProgramFromCode()` | ลบทั้งใบแล้วเขียนใหม่จากโค้ด — **ท่าที่แก้ในชีตหายหมด** ใช้ตอนแก้ชีตจนพัง |

แยกสองชื่อเพราะหลังเติมครั้งแรก **ชีตคือของจริง** การกดผิดจากเมนู Run ไม่ควรลบงานของเจ้าของทิ้ง
หัวตารางและรูปแบบคอลัมน์เป็นหน้าที่ของ `setup()` ที่เดียว — `seedProgram()` เขียนแต่ข้อมูล

## Session — เซสชันที่ทำจริง

## SetLog — รายเซ็ต

## Daily — ทุกเช้า
`date` `time` `pain` (0–10) `sleep_hrs` `where` (เข่า/ข้อศอก/ไหล่/หลังล่าง/ข้อเท้า) `note`

## วัดความก้าวหน้า — สองที่ คนละหน้าที่

### 1. ชีต "สรุป" — กราฟจริง
`gas/working/04_dashboard.gs` → Run `buildDashboard()` **ครั้งเดียว** จะได้ชีตชื่อ `สรุป`
พร้อมกราฟ 4 อัน · ใช้สูตร ไม่ใช่ค่าคงที่ → บันทึกเพิ่มจากแอปเมื่อไหร่ กราฟขยับเอง ไม่ต้องรันซ้ำ

| กราฟ | อ่านยังไง |
|---|---|
| ปวดตอนเช้า เฉลี่ยรายสัปดาห์ | **สำคัญที่สุด** — ควรลงหรือนิ่ง ถ้าขึ้นให้ลดโหลด 20% |
| น้ำหนักสูงสุดรายสัปดาห์ แยกท่า | ขึ้นช้า ๆ คือถูกแล้ว (ADR-0001) |
| ผลทดสอบ | ตัวชี้ขาดว่าโปรแกรมได้ผลไหม |
| จำนวนเซสชันต่อสัปดาห์ | ทำสม่ำเสมอไหม สำคัญกว่าทำหนัก |

เลย์เอาต์: **กราฟ 2×2 อยู่มุมซ้ายบน** · ตารางดิบที่กราฟดึงไปใช้ซ่อนอยู่คอลัมน์ `T` เป็นต้นไป
รันซ้ำได้ตลอด (ลบชีตเดิมแล้วสร้างใหม่) — ชีตนี้ไม่เก็บข้อมูลของตัวเอง ดึงจากใบอื่นล้วน

> ⚠️ **คอลัมน์สัปดาห์เป็นตัวเลข ไม่ใช่วันที่** — เกิดจาก `วันที่ − WEEKDAY()` ซึ่งได้ผลเป็นตัวเลข
> `format Col1 'yyyy-mm-dd'` ใน QUERY จึงไม่มีผล (เจอจริงตอนรันครั้งแรก ขึ้นเป็น `46258`)
> ต้อง `setNumberFormat('yyyy-mm-dd')` ที่คอลัมน์ผลลัพธ์แทน — `block_()` ทำให้แล้ว
>
> แล้วจะเจอกับดักต่อเนื่องอีกอัน: Sheets เอารูปแบบวันที่นั้น**ไปใช้กับแกน Y ของกราฟด้วย**
> น้ำหนัก 7.5 กก. เลยโชว์เป็น `1900-01-07` — แก้ด้วย `setOption('vAxis', {format:'#,##0.##'})`

### 2. แท็บ "ก้าวหน้า" ในแอป — ตัวเลขล้วน ไม่มีเส้นกราฟ
`?action=progress` คิดสรุปฝั่งชีตแล้วส่งกลับแค่ตัวเลขไม่กี่ตัว (สัญญาณไม่ดี — ยิ่งเบายิ่งดี)
เทียบ **28 วันล่าสุดกับ 28 วันก่อนหน้า**: ปวดตอนเช้า · ชั่วโมงนอน · จำนวนเซสชัน ·
น้ำหนักสูงสุดต่อท่า · ผลทดสอบ (ล่าสุดเทียบครั้งก่อน)

- แคชคำตอบล่าสุดไว้ — เปิดตอนไม่มีเน็ตก็ยังเห็น พร้อมวันที่กำกับ
- **ตัวชี้วัดที่น้อยลง = ดีขึ้น** อยู่ในลิสต์ `PROGRAM.lowerIsBetter` (`dropoff` · `recovery`)
  เพิ่มท่าทดสอบใหม่ที่น้อยลงดีขึ้นต้องมาเติม id ที่นั่นด้วย ไม่งั้นการ์ดอ่านผิดทาง
- ทิศทางที่แย่ลงแสดงเป็น**เทา ไม่ใช่แดง** — แอปนี้ไม่ควรกระตุ้นให้ดันหนักขึ้น (หลักการข้อ 4)
  สีแดงเก็บไว้ให้กรณีเดียว: **ปวดตอนเช้าเพิ่มขึ้น ≥ 0.5** → ขึ้นแถบเตือนให้ลดโหลด 20%
- ⚠️ endpoint นี้เปิดสาธารณะ — เจ้าของรับทราบและเลือกเอง ดู `docs/SCOPE.md`

**ยังคงไม่เขียนหน้ากราฟ (เส้น) ในแอป** — เส้นกราฟเป็นงานที่ Google ทำให้ฟรีและดีกว่า
สิ่งที่แอปทำแล้วชีตทำไม่ได้คือ *ตอบให้เร็วตอนยืนอยู่ข้างสนาม* จึงเหลือแค่ตัวเลข
