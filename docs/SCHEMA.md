## ⚠️ คอลัมน์ที่ต้องเป็นข้อความล้วน
Google Sheets แปลงค่าที่ "หน้าตาเหมือนวันที่" ให้เองเงียบ ๆ — เจอจริงตอนทดสอบ:
`3-1-1` (จังหวะ) กลายเป็น 3 ม.ค. 2001 · `6/7` (ทำครบกี่ท่า) กลายเป็น 6 ก.ค. · `6-8` (ช่วงครั้ง) กลายเป็นวันที่

`setup()` จึงบังคับ `setNumberFormat('@')` ให้คอลัมน์เหล่านี้ (ดู `TEXT_COLS` ใน `00_setup.gs`):
`Program.reps` `Program.tempo` · `Session.done` · `SetLog.reps` `SetLog.note`

คอลัมน์ `date` กับ `time` **ปล่อยให้แปลงตามปกติ** — เป็นวันที่/เวลาจริงแล้วทำกราฟง่ายกว่า

## Program — นิยามโปรแกรม
| คอลัมน์ | ความหมาย |
|---|---|
| `session_key` | `gym` · `homeA` · `homeB` · `easy` · `min` |
| `order` | ลำดับท่าในเซสชัน |
| `ex_id` `name` | รหัสท่า + ชื่อที่แสดง |
| `type` | `hold` ท่าค้าง · `reps` ยก · `interval` · `time` จับเวลา — กำหนดว่านาฬิกาทำงานยังไง |
| `sets` `reps` `tempo` `hold` `rest` | โดส (`hold`/`rest` เป็นวินาที) |
| `cue` `alt` `why` | คำเตือนฟอร์ม · ตัวสำรองถ้ายิมไม่มีเครื่อง · เหตุผลที่มีท่านี้ |

**★ แก้โปรแกรม = แก้แถวในใบนี้ ไม่ต้อง deploy ใหม่** — เหตุผลที่ออกแบบแบบนี้คือโปรแกรมถูกปรับ
13 จุดตั้งแต่ฉบับแรก และจะปรับอีกเรื่อย ๆ · `frontend/program.js` เป็นแค่ตัวสำรองตอนออฟไลน์

## Session — เซสชันที่ทำจริง
`date` `time` `session_key` `mins` `done` (เช่น `6/7` = ทำ 6 จาก 7 ท่า)

## SetLog — รายเซ็ต
`date` `time` `session_key` `ex_id` `ex_name` `set_no` `weight` `reps` `note`
ท่าค้างบันทึกเป็น `reps = "45 วิ"` และ `note = "hold"`

## Daily — ทุกเช้า
`date` `time` `pain` (0–10) `sleep_hrs` `where` (เข่า/ข้อศอก/ไหล่/หลังล่าง/ข้อเท้า) `note`

> ใบนี้สำคัญที่สุด — คะแนนปวดตอนเช้าคือตัวชี้วัดเอ็นที่ดีที่สุดที่วัดเองได้
> ถ้าค่าเฉลี่ยรายเดือนเพิ่มขึ้น = ช่องว่างกล้ามเนื้อ–เอ็นกำลังเปิด ให้ลดโหลด 20%

## Test — ทดสอบรายเดือน + วันแบด
`date` `time` `test_id` `test_name` `value` `unit`
`test_id` ที่ใช้: `wallsit_max` · `calf_max` · `pushup_max` · `recovery` (วินาทีจนพูดได้เต็มประโยค)

## ล้างข้อมูล — รันจาก editor (`clasp open-script` → เลือกฟังก์ชัน → Run)

อยู่ใน `gas/working/02_maintenance.gs` · ลบเฉพาะแถวข้อมูล **หัวตารางแถวที่ 1 อยู่ครบเสมอ**
และ **ไม่แตะชีต `Program`** เพราะนั่นคือนิยามโปรแกรม ไม่ใช่บันทึกการฝึก

| ฟังก์ชัน | ทำอะไร |
|---|---|
| `countRows()` | นับแถวแต่ละชีต — **รันอันนี้ก่อนเสมอ** จะได้เห็นว่ากำลังจะลบอะไร |
| `clearLogs()` | ล้างบันทึกทั้งหมด (Session · SetLog · Daily · Test) |
| `clearSetLog()` | ล้างเฉพาะรายเซ็ต |
| `clearDaily()` | ล้างเฉพาะคะแนนปวดตอนเช้า |
| `clearTest()` | ล้างเฉพาะผลทดสอบ |
| `clearSession()` | ล้างเฉพาะรายการเซสชัน |
| `resetAll()` | ล้างทุกบันทึก + ลงหัวตารางและรูปแบบคอลัมน์ใหม่ |

ผลลัพธ์ดูได้ที่ **Execution log** ในตัว editor (บอกว่าลบไปกี่แถวต่อชีต)

> ⚠️ **ล้างที่นี่ = ล้างฝั่งชีตเท่านั้น** ประวัติในมือถือเป็นคนละชุด
> ต้องล้างแยกที่แอป: แตะป้ายมุมขวาบน → "ล้างประวัติในเครื่อง"
> ถ้าล้างแค่ฝั่งชีต แอปจะยังนับรอบต่อจากของเดิมอยู่

## ทำกราฟ
**อย่าเขียนหน้ากราฟในแอป** — เปิดชีตแล้วใช้ Insert → Chart ของ Google เอา ฟรีและดีกว่าที่เราจะเขียนเอง
กราฟที่ควรทำ: `Daily.pain` รายวัน · `SetLog.weight` ของ `legpress`/`rdl` รายสัปดาห์ · `Test.value` แยกตาม `test_id`
